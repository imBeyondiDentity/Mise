# История изменений

## 1.2.0 - 2026-10-08

- Чип справа внизу теперь называется «Github» и открывает репозиторий `imBeyondiDentity/Mise` в новой вкладке (раньше было «← iDentity» со ссылкой на `../`).
- Адрес GitHub Pages в README, README_ru и PDF-гайде приведён в соответствие с реальным именем репозитория (`/Mise/`).
- `LICENSE` переформатирована короткими строками, чтобы не скроллить по горизонтали на телефоне.
- Стиль выпадающих списков переписан одним правилом фона со встроенной стрелкой (прошлое исправление на iPhone всё ещё показывало серые системные списки с огромной стрелкой).
- Нативные выпадающие списки заменены собственной «лицевой» частью (системный список по-прежнему открывается по тапу): Safari упорно перекрашивал их в серый с огромной стрелкой. В подвале теперь указана версия (v1.2.2).
- Подвал переделан, как в остальных проектах: чипы встроены в страницу и больше не плавают, слева «Github», справа «Написать» со ссылкой на почту автора, а между ними название MiSE с оранжевыми точками.
- Переключатель языка закреплён в шапке (прокручивается вместе со страницей, а не плавает), как в остальных проектах.
- Подпись «Модель» теперь стоит по центру над переключателем версии.

## 1.1.0 - 2026-10-08

- Инструмент получил имя **MiSE**. В шапке теперь только название по центру и маленькая двуязычная строка над ним; два предложения-слогана убраны.
- Название MiSE подставлено во вкладку браузера, экспорт `.json` и документацию.
- README и README_ru переписаны в формате Trio: пилюли-бейджи лицензии и «Open MiSE», переключатель языка, структура, публикация на GitHub Pages, ограничения.
- Добавлен `MiSE_guide.pdf`: двуязычный (RU и EN) гайд по всем функциям простыми словами, для пятиклассника.
- Исправлены выпадающие списки и поля, которые в Safari на iPhone выглядели как системные (добавлены сбросы `-webkit-appearance`); iOS больше не приближает страницу при фокусе на поле.
- Исправлена кнопка «Убрать пустые слова» во вкладке «Улучшить мой промпт»: она оставляла точку в начале текста.

## 1.0.0 - 2026-10-08

- Первый релиз: Seedance 2.0 и 2.5 в одном генераторе, интерфейс RU/EN.
- Движок правил: 13 архетипов сцен, физические схемы света, правила безопасности камеры, расчёт таймингов, извлечение речи.
- Режим LLM (мета-промпт), режим улучшения с линтером, история с избранным, ссылки для шеринга, экспорт `.txt` и `.json`.
