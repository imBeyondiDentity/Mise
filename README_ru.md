# MiSE

[![Licence: MIT](https://img.shields.io/badge/Licence-MIT-yellow.svg)](LICENSE)
[![Open MiSE](https://img.shields.io/badge/Open-MiSE-ff6a1a?style=flat)](https://imbeyondidentity.github.io/MiSE/)

[English version](README.md)

**MiSE** компилирует промпты для **Seedance 2.0 и 2.5**. Ты описываешь ролик обычными словами, а MiSE понимает замысел, выбирает формат промпта под нужную модель и режет сюжет на тайминги.

Всё работает в браузере. Без сервера, без загрузки файлов, без аккаунта и без API-ключа. После загрузки страницы работает и офлайн.

## Что умеет

1. **Читает бриф.** Определяет тип сцены (13 видов, от экшена до природы), свет, погоду, движения камеры, формат кадра, речь и порядок событий, и показывает, что понял.
2. **Собирает промпт.** Для Seedance 2.0 нумерованные шоты, для 2.5 посекундные отрезки (`0-5s:`). Свет описан как физическая схема (источник, угол, Kelvin), камеры и объективы названы по именам, движения камеры не выходят за то, что модель держит.
3. **Проверяет себя.** Тот же линтер, что работает во вкладке «Улучшить мой промпт», ставит результату оценку из 100.

## Режимы

- **Компиляция:** движок правил. Бесплатно и офлайн.
- **Режим LLM:** готовый мета-промпт с правилами Seedance внутри. Вставь его в Claude или ChatGPT и получи полностью английский, отполированный промпт.
- **Улучшить мой промпт:** вставь любой промпт и получи оценку, список проблем и быстрые правки в один клик (убрать пустые слова, добавить constraints).
- **История:** сохранённые промпты с избранным, повторное открытие и копирование. Хранится только в твоём браузере.

Также: интерфейс RU/EN, переключатель Seedance 2.0/2.5, референсы с ролями (`@Image1`, `@Video1`, `@Audio1`), музыка, звуковые эффекты и речь, формат кадра (для 2.5 можно свой), таймлайн, экспорт в `.txt` и `.json`, ссылки для шеринга.

## Различия версий

| | Seedance 2.0 | Seedance 2.5 |
|---|---|---|
| Длина | 4–15 с | 4–30 с |
| Файлы | 12 (9 картинок, 3 видео, 3 аудио) | 50 (30 картинок, 10 видео, 10 аудио) |
| Структура | нумерованные `Shot N`, время по желанию | отрезки подряд в целых секундах |
| Формат кадра | фиксированный список | любой от 0.4 до 2.5 |
| Доп. роли | нет | правка и продолжение клипа |

## Запуск локально

Открой `index.html` в любом современном браузере. Сборки и зависимостей нет. Шрифты подтягиваются с Google Fonts, а без интернета заменяются системными.

## Публикация на GitHub Pages

1. Создай репозиторий (например `MiSE`) и залей файлы в ветку `main`.
2. Открой *Settings*, затем *Pages*.
3. В *Build and deployment* выбери *Deploy from a branch*, ветка `main`, папка `/ (root)`.
4. Через минуту сайт заработает по адресу `https://<username>.github.io/MiSE/`.

Ссылка «← iDentity» справа внизу ведёт на `../`. Если страница лежит в другом месте, поменяй `href` у `#backLink`.

## Ограничения

- Движок правил не переводит. Каркас английский, твои формулировки остаются как написаны. Для полностью английского промпта используй режим LLM.
- «Русский через украинский тег» для речи — обходной путь сообщества, а не официальная функция.
- Правила взяты из официальных гайдов Seedance, практики сообщества и скилла `seedance-prompt-engineer` от iDentity. MiSE предлагает, решает модель. Генерации он не запускает, поэтому результат на платном генераторе может отличаться.
